# My Portfolio
<p>If you want to use my code you need env file:</p>

- NEXT_LINK
- ENVIRONMENT
- SITE_URL
- MONGO_URL
- SECRET_KEY
- TELEGRAM_BOT_TOKEN (contact form, server-side only)
- TELEGRAM_CHAT_ID (contact form, server-side only)

Copy `.env.example` to `.env.local` and fill in values. If a bot token was ever committed to git, rotate it in [@BotFather](https://t.me/BotFather).
